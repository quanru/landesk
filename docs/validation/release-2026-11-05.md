# LanDesk 原生迁移预览版发布记录

## 候选与范围

- 应用版本：1.5.1，Flutter build 100。
- 功能基线：`ed7fb1353d5ae34e6d3e071c28c2557ebf171df0`。
- 本次用户已明确授权使用 GitHub Actions 发布预览版。
- 新入口：`.github/workflows/landesk-preview.yml`，仅手动运行；每次 run 的 `headSha` 固定构建源码。
- Flutter 3.44.1、Rust 1.82；依赖保持主线的 vcpkg 固定提交。
- 构建范围：Android arm64/armv7/x64、Windows x64、Linux x64、macOS Intel/Apple Silicon。iOS 使用本机发行签名后提交 TestFlight。

## 发布门槛

流水线先上传 Actions artifacts，没有公共 Release 写权限。构建完成后核验实际包名、版本、签名和 SHA-256，完成候选运行验证后再创建 GitHub prerelease。macOS 云端产物仍须本机发行签名及公证；Windows 暂无签名配置，必须明确标注 unsigned。构建成功不代表端到端远程连接验证成功。

原生预览版使用官方 RustDesk 协议，不兼容 legacy 协议；虚拟按键、局域网入口和 LanDesk 主题保留。公网中继、账号服务和浏览器远程入口不属于本次版本。
