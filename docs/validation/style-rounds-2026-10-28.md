## 改动

1. 页面层次：桌面侧栏 280 → 248，品牌图标 46 → 36；共享控件圆角 14 → 10，卡片 20 → 16；设置分组取消外框、使用浅灰表面，标题降低视觉权重。离线设备图标使用主题灰色。
2. 工具栏：普通 SVG 操作图标移除实心方块底，按亮暗主题显示；危险操作保留错误色，悬停、按下、键盘聚焦有反馈。自绘显示器缩略图仍保留原配色，未声称全部统一。
3. 适配回归：375×812 与 812×375、两倍字号、减少动态效果下，设置分组布局和勾选/输入行为通过测试。
4. 实际窗口走查后：LAN 空状态改为平静的标题及网络/IP 连接说明，长文案可滚动，未修改原有翻译文件。
