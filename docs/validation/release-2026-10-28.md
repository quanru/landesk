## Re-sign a device app from an archive

```
ditto flutter/build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app dist/releases/ios-device/Runner.app
python3 tools/localdesk/sign-ios.py --app dist/releases/ios-device/Runner.app --identity '<development identity>' --profile '<device profile>'
xcrun devicectl device install app --device '<device ID>' dist/releases/ios-device/Runner.app
xcrun devicectl device process launch --device '<device ID>' dev.quanru.localdesk
```
