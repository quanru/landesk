## 发布门槛

- Windows/Linux：检查对应候选实际窗口；Windows 未签名，Linux 验证范围限定 X11，不冒充 Windows 11 或 Wayland 主机完整认证。
- macOS：双架构 Developer ID 签名、公证、staple 和严格签名校验；Apple Silicon 实际启动，Intel 没有物理硬件时明确保留运行验收缺口。
- Android：固定证书与版本／ABI 校验，ARM64 设备安装和启动；其他 ABI 没有实际设备证据时准确标注。
- iOS：新 archive 使用 App Store 发行签名，IPA 版本／build／桥接导出及上传结果核验，沿用既有测试组，区分上传、处理、外部审核和公开可安装。
- 对外文件：飞书固定主文件与 GitHub 备用文件精确对应，同步后回读 SHA-256；不使用飞书预览页作为自动更新接口。
- 官网只在公开文件确定后更新，三语下载及 production 提交均需核验。
