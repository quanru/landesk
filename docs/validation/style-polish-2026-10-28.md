# 素雅组件走查（2026-10-28）

本轮修正共享文本按钮、图标按钮、复选框、开关和单选框的禁用状态；增强未选中复选框边界；Android 触控按钮最小尺寸改为 48，iOS 保持 44，桌面保持紧凑尺寸。密码显示图标随亮暗主题切换；密码强度条改为细圆角分段，保留强度文字和弱密码错误色；移动端手势模式切换使用语义配色。

验证：
- theme、theme preview、source license 合计 17 项测试通过。
- custom_password / gesture_help 分析无问题；主题和 dialog 存在原有弃用提示及一个原有 unused_local_variable 警告，无分析错误。
- macOS release 1.3.0 (79) 编译通过。
- 亮暗组件预览无溢出；部分文字仍显示测试字体块，不能作为完整视觉验收。
